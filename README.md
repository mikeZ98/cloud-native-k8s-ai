# cloud-native-k8s-ai

Production Kubernetes & IaC infrastructure for AI microservices: a FastAPI inference service,
Qdrant as a StatefulSet, Redis, KEDA event-driven autoscaling, default-deny NetworkPolicies and a
Terraform bootstrap. All validation is hermetic and static: no live cluster, no cloud APIs.

Status: bootstrapping. See [CONTRIBUTING.md](CONTRIBUTING.md) for setup and quality gates.
